# Press Release Performance Analytics

> Measuring PR impact through data — tracking pickup rates, geographic reach, and ROI across media distribution channels.

**Author:** Caleb Agyemang
**Role:** PR & Data Analytics Professional
**Stack:** Python, Pandas, Matplotlib, Seaborn

---

## Overview

This project analyzes the performance of a press release campaign across 12 media outlets, tracking pickup rates, audience impressions, geographic distribution, time-to-coverage patterns, and ROI correlation. The goal: demonstrate that PR activities produce measurable, quantifiable business impact.

Using Python and pandas, the dataset was cleaned, normalized, and enriched with UTM tracking metadata. Visualization was handled with matplotlib and seaborn, producing publication-ready charts suitable for boardroom presentations.

## Methodology

**Pickup Rate Calculation:** Measured as the percentage of targeted outlets that published the press release. Tier 1 outlets (Bloomberg, AP News, Reuters, TechCrunch) were weighted higher based on audience reach.

**Geographic Distribution:** Outlets were categorized by primary audience region. Impressions were aggregated per region to show market penetration.

**ROI Attribution:** UTM-tracked links were compared against organic (non-tracked) distribution to measure the lift provided by social promotion and targeted outreach.

**Time-to-Coverage:** Tracked the number of hours between distribution and first publication per outlet. Tier 1 outlets showed faster pickup, confirming the importance of pre-existing media relationships.
