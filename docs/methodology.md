# Methodology — Press Release Performance Analytics

## Key Metrics

### Pickup Rate
Percentage of targeted outlets that published the press release.

```
Pickup Rate = (Outlets Published / Outlets Targeted) × 100
```

### Impressions
Estimated audience reach based on outlet circulation/readership data.

```
Impressions = Outlet Audience × Pickup Probability
```

### Click-Through Rate (CTR)
Measures how effectively the press release drives traffic.

```
CTR = (Clicks / Impressions) × 100
```

### Time-to-Coverage
Hours between distribution and first publication. Shorter times indicate stronger media relationships.

## Tier Classification

| Tier | Examples | Typical Pickup |
|------|----------|---------------|
| Tier 1 | Bloomberg, AP News, Reuters, TechCrunch | 80-95% |
| Tier 2 | Forbes, Yahoo Finance, MarketWatch | 65-85% |
| Tier 3 | Regional, niche, trade publications | 40-65% |

## UTM Attribution

UTM parameters enable precise attribution of traffic to specific press release distributions:

- `utm_source=newswire` — Wire service distribution
- `utm_medium=press_release` — PR-specific traffic
- `utm_campaign=q3_launch` — Campaign-level grouping

Comparing UTM-tracked vs. organic CTR reveals the lift provided by social promotion and targeted outreach.
